# Bilingual Transcriber - 現地監査音声認識・翻訳システム (v3.1.1)

Google Gemini Live API (`models/gemini-3.5-transcribe-live`) およびブラウザ標準音声認識（Web Speech API）に対応した、現地監査・国際会議向けの音声認識・長文文脈翻訳・任意範囲サマリー・Googleドキュメント一元同期Webアプリケーションです。

---

## 🚀 主な機能・特徴 (v3.1.1 最適化・監査済リリース)

### 1. v3.1.1 最適化リファクタリング＆監査修正
- **共通テキストAPIクライアント統合 (`GeminiTextClient`)**: 翻訳とサマリーで重複していた Gemini REST API カスケードフォールバック・最適モデルキャッシュを統合し、両機能で最速・最安定モデルを共有。
- **インライン編集（✏️）の同期バグ修正**: 翻訳完了後にカードを編集する際、訳文欄が空になる不具合を解消し、常に最新の原文・訳文を安全に編集可能。
- **排他制御＆メモリ保護**: 録音開始ボタンの連打二重起動ロック (`isStarting`)、Googleドキュメント保存の同時多重実行ロック (`isSavingDocs`)、削除済みカードの遅延翻訳ガード、および動作ログのDOM上限（300行）を実装。
- **スマホ向けカードヘッダの1行スリム化＆操作プルダウン化 (v3.1.1)**: コピー・修正・再翻訳・削除の4ボタンを `⋯ ▾` プルダウンメニューへ集約し、話者ラベルを短縮表示（`Yard` / `Auditor` / `Facility` / `Other`）、言語バッジを国旗アイコン（Windowsでは `BD` / `JP` / `US` / `IN`）のみに整理。スマホ画面でもヘッダが確実に1行に収まり、一度に表示できるカード枚数を拡大。
- **スマホ連携QRコードの超軽量化・鮮明描画化 (v3.0.1)**: 既定値の省略・GASデプロイID圧縮・プリセットID化・Base64URL化によりQRデータ量を最大約85%削減（約2,000文字→約220文字）。さらに整数ピクセル描画＋ISO準拠4セル余白＋高コントラスト黒白描画によりスマホカメラでの読み取り性を抜本改善。
- **スマホ連携QR同期の完全化**: `folderId` のエクスポート漏れを修正し、UTF-8 Base64 処理とフォールバック付きクリップボードコピーを共通化。
- **CSS / イベント構造の正規化**: 重複セレクタおよび3か所に分散していた `@media (max-width: 767px)` を1ブロックへ統合し、`App._bindEvents()` を機能別メソッドへ分割。

### 2. 高精度VAD（音声区間検出）＋ モバイル・Wi-Fi安定化 (v3.1.1 監査修正反映済)
- **v3.1.1 監査指摘6件の完全修正**:
  - **Pre-Gain VAD＋Minimum Statistics 適応ノイズ追跡**: `gainNode` 前段から VAD 専用アナライザーを分岐し、マイク感度変更（1.0x〜3.5x）の影響を完全に排除。さらに直近 2.8 秒の最小 RMS 追跡により、騒音環境でも「発話送信中」張り付きを構造的に解消。
  - **WebSocket エラーコード判定修正**: `onerror` による `onclose(event.code)` 握りつぶしを解消し、認証・設定エラー（1007/1008）での無駄な自動リトライを防止。
  - **一時停止・自動保存・QR同期・UI整備**: 一時停止時の VAD バッジ＆メーター連動、録音停止時の翻訳完了待機を 22 秒へ延長、QR `#s=` 同期時の `gasToken` 空値クリア対応、カード削除に強い自動保存増分カウンタ、動作ログ開閉矢印の切り替えを実装。
- **翻訳精度を落とさない4段階VAD (`VoiceActivityDetector`)**:
  - **プリロール（先読み保持 400〜550ms）**: 発話検知時に直前バッファを遡って送信し、語頭の欠けを防止。
  - **ハングオーバー（余韻保持 1.4〜2.2秒）**: 息継ぎや短い間で送信を切らず、文脈と自然な発話リズムを維持。
  - **適応ノイズフロア＋音声帯域比解析**: 周囲の空調音・現場騒音を自動学習しつつ、200〜3,600Hzの音声帯域エネルギー比とヒステリシス判定で誤検知を低減。無音遷移時に `audioStreamEnd` を送信し、末尾認識を即確定しつつ無音時の通信量・API課金・ハルシネーションを大幅に削減。
  - **UI即時切替＆節約率表示**: 操作パネルから `自動 (標準)` / `敏感 (小声・遠距離)` / `強め (騒音現場向け)` / `OFF (常時送信)` を録音中でも即時切替可能。ライブ枠に状態と通信節約率（`-XX%`）をリアルタイム表示。

- **`audio` 単一送信化**: 非推奨の `mediaChunks` との2重送信を廃止し、音質・精度を落とさず必要上り帯域を **約 0.4 Mbps**・データ消費量を **約 160 MB / 時間** まで約50%削減。
- **瞬断時自動リトライ再接続**: モバイル回線切替や Wi-Fi ローミングで一時切断しても録音を止めず、最大5回（1.5s → 3s → 5s → 8s → 12s）自動再接続。最新約3.5秒分の音声チャンクを保持し、`online` 復帰時は待機をスキップして即再接続。

### 3. リアルタイム原語表示 ＋ 前文脈連動・長文日本語翻訳
- **長文バッファリング (`LongFormUtteranceBuffer`)**: ライブ枠に原語をリアルタイム連続表示しつつ、日本語訳時は息継ぎや細切れ断片で分割せず、無音4秒または260文字以上の文末で自然な段落へ一括翻訳（「⚡ 今すぐ翻訳」で即時確定可能）。
- **前文脈連動翻訳**: 翻訳実行直前に直近6件（`なし / 3 / 6 / 10件` 選択可）の時系列前文脈を動的取得し、指示語や専門用語を一貫させて翻訳。
- **翻訳プロンプト追記（テーマ・ニュアンス調整）**: メイン画面から4種プリセット＋自由記述でトーンや専門用語ルールを即時調整可能。
- **固定モード言語ロック**: 「固定: 英語 ➔ 日本語」選択時は英語・ラテン文字専用ロックを自動適用し、ヒンディー語等への誤認識を防止。

### 4. 任意タイミング・可変さかのぼり範囲サマリー出力 (`SummaryService`)
- 録音・翻訳を止めずに **「✨ サマリー出力」** から `直近 3/5/10/15/30/60分 / セッション全体 / カスタム分数指定` の会話を構造化日本語サマリー（要点・主なトピック・確認事項/課題）として出力・履歴切替・Markdownコピー可能。

### 5. 4言語同時自動認識・iPad/スマホ対応・Googleドキュメント一元同期
- 日本語・英語・ベンガル語・ヒンディー語の4言語自動判別と `code.gs` による単一Googleドキュメントへの完全上書き同期保存（`code.gs` も v3.1.1 へバージョン統一済み。既存の v2.9.0 デプロイのままでも完全互換で動作します）。
