# Multilingual Transcriber - 多言語音声認識・文脈翻訳システム (v3.4.0)

Google Gemini Live API（`models/gemini-3.5-transcribe-live`）およびブラウザ標準音声認識（Web Speech API）に対応した、国際会議・ビジネス雑談・現地監査向けの**多言語リアルタイム文字起こし・長文文脈翻訳・Gemini 4 進行中チェック/議事録サマリー・ローカル/Googleドキュメント議事録出力Webアプリケーション**です。

サーバー設置やビルド工程は一切不要で、ブラウザ（PC / iPad / スマートフォン）から開くだけで動作します。

## ✅ できること

### 1. 多言語リアルタイム音声認識 ＆ コードスイッチング（混在発話）補足
- **日英の認識精度を最優先しつつ、英語雑談中のヒンディー語・ウルドゥー語を拾い上げ（既定プロファイル）**:
  - インド英語アンカー（`en-IN`）を含む音響バイアス（`ja-JP`, `en-US`, `en-IN`, `hi-IN`, `ur-PK`）により、アクセントのある英語や日本語を誤変換させずに高精度認識しつつ、英語の雑談に混じるヒンディー語・ウルドゥー語の相槌やフレーズ（デーヴァナーガリー文字・ナスタアリーク体ウルドゥー文字・ローマ字 Hinglish / Roman Urdu）を自然に認識します。
- **用途に応じて選べる4段階の認識プロファイル**:
  1. `日英最優先 ＋ ヒンディー/ウルドゥー補足 (推奨)`: 日英会議＋南アジアメンバーとの雑談混在に最適。
  2. `完全多言語 (85+言語自動判別・日英優先)`: Gemini 3.5 Live の自動言語識別を開放し、85以上の言語と自由なコードスイッチングを認識。
  3. `カスタム言語セット`: 設定画面から最大20言語（日・英・中・韓・ベトナム・インドネシア・タガログ・タイ・ミャンマー・ヒンディー・ウルドゥー・ベンガル・アラビア・ペルシア・トルコ・スペイン・フランス・ドイツ・ポルトガル・ロシア・イタリア）を任意に組み合わせて認識候補を絞り込み。
  4. `日英2言語のみ厳密ロック`: 日本語と英語以外の文字出力を完全に遮断。
- **RTL（右横書き）とLTR（左横書き）の混在表示対応**:
  - ウルドゥー語・アラビア語・ペルシア語などの右横書き文字と英語が1つの発話内に混ざっても、文字順序や句読点が崩れない双方向レンダリング（`dir="auto"`, `<bdi>`, `unicode-bidi: plaintext`）に対応しています。

### 2. 前後の文脈を踏まえた長文・段落翻訳
- **リアルタイム原語プレビュー ＋ 段落まとめ翻訳 (`LongFormUtteranceBuffer`)**:
  - 発話中の原語は `🔴 LIVE リアルタイム原語表示` に遅れなく表示しつつ、翻訳時は細切れの断片ごとにぶつ切りにせず、自然な文末・段落単位（既定4秒の無音または260文字以上の文末）でまとめて読みやすい日本語（または相手言語）に一括翻訳します。
  - 英語の途中でヒンディー語・ウルドゥー語が混じってもカードを分断せず、1つのまとまった発話として文脈ごと翻訳します（複合言語バッジ `🇺🇸·🇮🇳` / `🇺🇸·🇵🇰` 等を自動表示）。
  - 待ち時間をスキップしたいときは **「⚡ 今すぐ翻訳」** ボタンでその瞬間に確定・翻訳できます。
- **直前の会話履歴を踏まえた文脈連動翻訳**:
  - 直近 `6件`（`なし / 3件 / 6件 / 10件` から変更可）の確定会話を自動で参照し、代名詞（it / they / that 等）や省略された主語、専門用語の訳語を前の発言と一貫させます。
- **5種類の翻訳ルーティング ＆ 20言語の相手言語選択**:
  - `自動双方向 (日 ⇄ 相手言語 / 多言語➔日)`、`集約: 全言語 ➔ 日本語`、`集約: 全言語 ➔ 相手言語`、`固定: 日本語 ➔ 相手言語`、`固定: 英語のみ ➔ 日本語 (英語ロック)` を切り替え可能。原文と翻訳先が同じ言語（混在なし）の場合はAPI呼び出しを自動スキップして即座に表示します。
- **翻訳プロンプト追記（テーマ・ニュアンス調整）**:
  - ワンクリックの5種プリセット（`💬 英雑談＋ヒンディー/ウルドゥー` / `🤝 会議・丁寧ビジネス` / `📋 監査・法令厳密` / `🏗️ 現場・口語かみ砕き` / `🎤 講演・パネル議論`）や自由記述で、訳文のトーンや専門分野の前提を録音中でも即座に調整できます。

### 3. 対面マイク集音 ＆ PC・タブ内部音声キャプチャ
- **遠距離マイク集音ブースト（対面会議・広い会議室・現場向け）**:
  - 80Hzハイパスフィルター（空調・低周波ノイズ除去）＋ 可変プリアンプゲイン（`1.0x`〜`3.5x`、既定 `2.5x`）＋ ダイナミクスコンプレッサー（音割れ防止）により、離れた席の声もクリアに集音します。
- **タブ・PC音声キャプチャ（Zoom / Teams / Meet / Web動画向け）**:
  - ワイヤレスイヤホンやヘッドホンで聴いているオンライン会議・動画の音声を、スピーカーから音を出さずにPC内部から直接キャプチャして認識・翻訳できます。
- **省通信・高精度VAD（音声区間検出）＆ 自動再接続**:
  - 無音時は通信を休止しつつ、語頭欠けを防ぐプリロール（400〜550ms）と余韻保持（1.4〜2.2秒）により認識精度を維持したまま通信量・API消費を削減します。
  - Wi-Fiローミングやモバイル回線の瞬断時も、直近約3.5秒の音声を保持したまま最大5回自動で再接続します。また、Gemini Live の10分セッション上限も裏側で自動更新されるため長時間会議でも途切れません。

### 4. Gemini 4 推論による2モード日本語サマリー ＆ 議事録プロンプト事前登録
- **Gemini 4 (`gemini-4-neon` ➔ `gemini-4-hydrogen` / 推論レベル `medium` 固定) 搭載**:
  - リアルタイム翻訳の高速モデルとは独立して、サマリー生成には高推論モデル **`gemini-4-neon`**（未対応キー時は **`gemini-4-hydrogen`** へ自動フォールバック、いずれも `thinkingLevel: "medium"` 固定・最大 `120,000` 文字入力対応）を使用。音声認識（ASR）誤変換の前後文脈からの自然な復元や、否定・除外表現（「実施しない・不要・対象外」等）の取り違え防止を徹底しています。
- **用途に合わせた2モード切替（`⚡ 進行中チェック` ⇄ `📋 議事録用`）**:
  - **`⚡ 進行中チェック`（既定）**: 打ち合わせ進行中に「聞き漏らした条件・数値がないか」「誤解や認識ズレが生じていないか」を数十秒で素早くチェックします。
  - **`📋 議事録用`**: 打ち合わせ後の振り返り・共有用の構造化サマリーを出力します。推奨プロンプト5種を初期収録しているほか、**ユーザー独自の議事録プロンプトを複数事前登録（新規保存・上書き・削除）**でき、その場でテキストエリアからプロンプトを**手入力調整**することも可能です。
  - 複数回出力したサマリーは履歴プルダウンからいつでも見比べ・Markdownコピーが可能です。

### 5. 議事録編集・ローカルファイル保存・Googleドキュメント同期・スマホ連携
- **GAS不要のローカルファイル保存（`📥 ファイル保存 ▾`）**:
  - Google Apps Script 未設定でもワンクリックで **Markdown（`.md`・最新サマリー込み）**、**Excel対応 CSV（`.csv`・UTF-8 BOM＋CRLFで文字化けなし）**、**プレーンテキスト（`.txt`）** を端末へ直接ダウンロードできます。
- **カードのインライン編集・話者切替・再翻訳・絞り込み検索**:
  - 各カードの話者バッジ（`Auditor` / `Yard` / `Facility` / `Other`）のワンクリック切替、`⋯ ▾` メニューからの原文・訳文修正（✏️・`Ctrl/⌘+Enter` 保存）、個別再翻訳（🔄）、削除（🗑️）に対応。
  - **キーワード検索**および**話者・言語・コードスイッチ混在フィルタ**で長い会議ログからも目的の発言を瞬時に絞り込めます。
- **ひとつのGoogleドキュメントへの完全同期保存 ＋ 冒頭サマリー自動添付 (`code.gs`)**:
  - 新規Googleドキュメント作成（保存先フォルダ指定可）および既存ドキュメントへの**上書き完全同期**に対応。`☑ 最新サマリーも冒頭に添付` がONのときは、事前にサマリーボタンを押していなくても保存時に自動でサマリーを生成してドキュメント冒頭へ添付します（旧バージョンのGASデプロイ環境でも自動フォールバックで欠落なく保存されます）。
- **QRコードによるスマホ・iPadへのワンタップ設定引き継ぎ**:
  - PCで設定したAPIキー・GAS URL・言語設定一式を超軽量圧縮QRコード（`#s=...`）として表示し、スマホやiPadのカメラで読み取るだけで即座に同じ環境を再現できます。

### 6. 長時間会議を支える快適UX・データ保護機能
- **未保存セッションの自動下書き保護 ＆ 誤閉鎖防止**:
  - 録音中や未保存データがある状態でタブを閉じようとすると確認ダイアログ（`beforeunload`）で保護。万が一ブラウザが強制終了・リロードされても、次回起動時に **「↩️ 前回のセッションを復元」** バナーから発話とサマリーを復元できます。
- **画面スリープ防止（Screen Wake Lock）＆ 経過時間タイマー**:
  - 録音中はスマホ・iPad・PCの画面自動消灯を防止（タブ復帰時も自動再取得）し、ヘッダとミニバーに経過時間（`🔴 MM:SS`）を表示します。
- **上部固定ミニLIVEバー ＆ 過去カード閲覧時のスクロール位置維持**:
  - 過去の翻訳カードを読むために下へスクロールすると、画面上部にスリムなミニLIVEバー（経過時間・音量メーター・最新原語・`⚡` / `⏸️` / `⏹️` / `↑`）が自動出現。新着カードが追加されても読んでいる位置が勝手に飛ばず、`↑ 新着の発話 N件` ボタンでいつでも先頭へ戻れます。
- **すっきり整理された操作パネル・マイク選択・文字サイズ・ダークモード・ショートカット**:
  - 普段使う基本操作だけを1段目に残し、分野・区切り・文脈・感度・VAD・**使用マイク選択**・Docs保存先は折りたたみ式の **「🎛️ 詳細・音響設定」** に集約（録音開始時に自動で閉じて画面を広く確保）。
  - ワンクリックの**文字サイズ3段階切替（`🅰 標準 / 大 / 特大`）**、目に優しい**ライト／ダークモード切替（`🌙 / ☀️`）**、および **`Alt+R` 等のキーボードショートカット**に対応しています。

## ⚠️ できないこと（制約・仕様上の限界）

利用前に以下の技術的・仕様上の制限事項をご留意ください。

1. **完全オフライン（インターネット未接続）環境では動作しません**
   - 音声認識（Gemini Live API / Web Speech API）および翻訳・サマリー生成（Gemini REST API / GAS）はいずれもクラウド通信を行うため、インターネット接続が必須です。
2. **翻訳音声の読み上げ（TTS / 合成音声出力）機能はありません**
   - 本アプリはリアルタイム文字起こし・画面上での対訳表示・要約・議事録化に特化しており、翻訳結果をスピーカーから音声として読み上げる機能は搭載していません（マイクへの回り込みハウリング防止のため）。
3. **声紋による自動話者分離（オートダイアライゼーション）はできません**
   - 発話言語に応じた初期話者ロールの自動振り分け（日本語＝`Auditor`、外国語＝`Yard Rep`）は行いますが、「英語を話すAさんとBさんを声質で自動区別する」機能はありません。必要に応じてカード上の話者バッジをクリックして切り替えてください。
4. **録音音声ファイル（MP3 / WAV等）自体の保存・ダウンロード機能はありません**
   - プライバシー保護およびメモリ軽量化のため、マイク音声はリアルタイムでPCMストリーム送信された後に破棄され、ブラウザやサーバーに音声データは残りません（保存されるのはテキスト議事録のみです）。
5. **スマートフォン / iPad 単体では「タブ・PC音声キャプチャ」は使えません**
   - ブラウザ標準仕様（`getDisplayMedia`）の制限により、システム音声・タブ音声の内部キャプチャは **PC版 Chrome / Edge** 限定です。iOS / iPadOS / Android では「マイク（対面会話）」モードをご利用ください。
6. **ローカルファイルの直接ダブルクリック起動（`file://`）ではマイクが使えません**
   - ブラウザのセキュリティ制約により、`https://`（GitHub Pages 等）または `http://localhost` 経由で開く必要があります。
7. **同時発話（クロストーク）や極端な騒音下での完全分離には限界があります**
   - 複数人が同時に重なって話した場合、1つの発話として結合されたり片方の声が優先されたりすることがあります。また、ブラウザ標準認識（`Web Speech API` フォールバック時）は一度に単一言語しか待ち受けられないため、多言語混在・コードスイッチング認識には **Gemini Live API** の利用が必須です。
8. **未保存セッションの自動下書きはそのブラウザ内（端末ローカル）限定です**
   - 誤リロード時に復元できる自動下書き（`localStorage`）を備えていますが、別端末とは自動同期されず、シークレット（プライベート）ブラウズ終了時やサイトデータ消去時には消えます。終了時は必ず **「📥 ファイル保存」** または **「💾 Google ドキュメントに保存」** で議事録を保存してください。

## 📖 使用方法

### ステップ 1：事前準備（初回のみ）
1. **Gemini API キーの取得（必須）**
   - [Google AI Studio](https://aistudio.google.com/apikey) にアクセスし、APIキー（`AIza...`）を発行します。
2. **アプリを開く**
   - GitHub Pages の公開URL（`https://defshine-git.github.io/Livetrans/`）、またはローカルサーバー（`npx serve .` や `python3 -m http.server 8080` 等で起動した `http://localhost:8080`）を Chrome / Edge / Safari で開きます。
3. **APIキーの登録**
   - 初回表示されるセットアップカードの **「🔑 APIキーを登録」**（または画面右上の **「⚙️ 設定」**）を開き、「Gemini API キー」欄に入力して **「設定を保存」** を押します（キーは自分のブラウザ内 `localStorage` にのみ保存され、外部第三者サーバーへは送信されません）。

### ステップ 2：音声認識・翻訳の開始
1. 操作パネル上段で基本項目を選びます（迷ったらすべて初期値のままで問題ありません）：
   - **音源**: 対面会議なら `マイク (対面会話)`、PCでのWeb会議視聴なら `タブ・PC音声`
   - **認識**: 通常・インド/パキスタン系メンバーとの英語会議なら `日英最優先 ＋ ヒンディー/ウルドゥー補足 (推奨)`、多国籍会議なら `完全多言語` または `カスタム言語セット`（選択時は直下に言語バッジと `⚙️ 変更` ボタンが表示されます）
   - **翻訳**: 日英（または相手言語）の双方向通訳なら `自動双方向`、外国語をすべて日本語で読みたい場合は `集約: 全言語 ➔ 日本語`
   - **相手言語**: 日本語から翻訳したい相手の言語（既定は `🇺🇸 英語`、計20言語から選択可）
   - ※ 分野・区切り秒数・文脈参照件数・マイク感度・VAD・**使用するマイク入力機器の切り替え**・Googleドキュメント保存先は **「🎛️ 詳細・音響設定」** を開くと変更できます。
2. **「🎤 録音開始」** ボタンを押します（ショートカット: `Alt + R`）。
   - ※ `タブ・PC音声` を選んだ場合は、共有するブラウザタブまたは画面を選び、ダイアログ左下の **「タブの音声も共有（システムオーディオを共有）」に必ずチェック** を入れて共有を開始します。
3. 発話すると `🔴 LIVE リアルタイム原語表示` に原語がリアルタイム表示され、一区切りつくと自動的に `確定翻訳タイムライン` の先頭に対訳カードが追加されます。
   - 話の途中ですぐに訳文を見たいときは **「⚡ 今すぐ翻訳」**（`Alt + Enter`）を押します。
   - 過去ログへスクロールしても画面上部の**ミニLIVEバー**で進行中の発話確認・即時翻訳・一時停止・停止が可能です。

### ステップ 3：会議中の進行中チェック・終了後の議事録サマリー・ローカル保存
- **進行中の聞き漏らし・誤解チェック**: 録音したまま `📝 会話サマリー` バーを **`⚡ 進行中チェック`** にして範囲（例: `直近 5分` や `直近 15分`）を選び、**「✨ サマリー出力」**（`Alt + S`）を押すと、「いまの話の要点 / 聞き漏らし注意ポイント / 誤解・認識ズレ確認事項」が素早く整理されます。
- **終了後の議事録用サマリー＆プロンプト調整**: **`📋 議事録用`** に切り替え、推奨テンプレート5種または自分で事前登録したプロンプトを選んで出力します。**「✏️ プロンプト調整・登録」** を開けば、テキストエリアでプロンプトを手入力で微調整したり、名前を付けて **「💾 事前登録として保存」** して次回以降もすぐ呼び出したりできます。
- **発言を検索・絞り込む**: タイムライン上部の検索欄（`/` キーで即移動）や話者・言語・混在フィルタで該当カードだけを絞り込めます。
- **カードを編集・再翻訳する**: 各カード右上の `⋯ ▾` ボタンから `📋 コピー` / `✏️ 修正`（`Ctrl/⌘ + Enter` で保存、`Esc` でキャンセル）/ `🔄 再翻訳` / `🗑️ 削除` が行えます。
- **ローカルファイルに保存する（GAS不要）**: `📥 ファイル保存 ▾` から **Markdown (`.md`)**、**CSV (`.csv`)**、**テキスト (`.txt`)** を選んでその場でダウンロードできます。

### ステップ 4：スマホ・iPad連携（任意）
1. 設定済みのPC画面右上にある **「📱 スマホ連携」** ボタンを押すとQRコードが表示されます。
2. スマートフォンやiPadの標準カメラでQRコードを読み取り、開いたリンクにアクセスするだけで、APIキー・GAS設定・選択モード一式が自動インポートされます（URLハッシュ `#s=...` はインポート直後にアドレスバーから自動消去される安全設計です）。

### ステップ 5：Googleドキュメント自動保存のセットアップ（任意）
Googleドキュメントへの直接保存を使いたい場合は、同梱の `code.gs` を Google Apps Script としてデプロイします。
1. [Google Apps Script](https://script.google.com/) で「新しいプロジェクト」を作成し、`code.gs` の中身を貼り付けて保存します。
   - ※ 旧バージョンの `code.gs` がデプロイされている状態でも後方互換フォールバックにより冒頭サマリー＋全発話が保存されますが、見出し（`HEADING2` / `HEADING4`）や箇条書き装飾付きのネイティブ出力を使う場合は最新の `code.gs` (v3.4.0) に貼り替えて「デプロイを管理 ＞ 編集 ＞ 新しいバージョン」で更新してください。
2. （任意）プロジェクトの設定 ＞ **スクリプト プロパティ** に以下を設定すると、既定フォルダや認証トークンを固定できます：
   - `OUTPUT_FOLDER_ID`: 保存先GoogleドライブのフォルダID
   - `SECRET_TOKEN`: 不正アクセス防止用の任意の合言葉文字列
   - `SPREADSHEET_ID`: 専門用語辞書スプレッドシートID（利用する場合）
3. 右上の **「デプロイ」＞「新しいデプロイ」** を開き、種類で **「ウェブアプリ」** を選択します。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員（Anyone）** ※CORS通信のために必須
4. 発行されたウェブアプリURL（`https://script.google.com/macros/s/.../exec`）をコピーし、本アプリの **「⚙️ 設定」＞「GAS Web App URL」** に貼り付けて **「GAS接続テスト」** で `✓ 接続成功` が出ることを確認して保存します。
5. 以降、メイン画面の **「💾 Google ドキュメントに保存」** を押すだけで、冒頭サマリー（未出力時は自動生成）＋確定済みの全カードが1つの整ったGoogleドキュメントとして作成・上書き同期されます。

## 💡 実戦活用 Tips

### 🎯 言語認識・コードスイッチングの使い分け
- **インド・パキスタン等の技術者・担当者との英語打ち合わせ**:
  - 認識プロファイルを既定の **`日英最優先 ＋ ヒンディー/ウルドゥー補足`** にしておき、`✨ 翻訳プロンプト追記` から **`💬 英雑談＋ヒンディー/ウルドゥー`** プリセットをONにするのがベストです。英語の専門用語は正確に英語として拾いつつ、雑談で混じる `acha`, `theek hai`, `yaar`, `inshallah`, `सब ठीक है` 等のニュアンスも自然な日本語訳に反映されます。
- **英語と日本語しか絶対に使わない会議で誤認識をゼロにしたい場合**:
  - 認識プロファイルを **`日英2言語のみ厳密ロック`** にするか、相手が英語のみを話す場面では翻訳モードを **`固定: 英語のみ ➔ 日本語 (英語ロック)`** に切り替えると、強い訛りや周囲の物音が他言語文字に化ける現象を完全に防げます。
- **東南アジア・欧州など特定の3〜5言語が飛び交う会議**:
  - `完全多言語 (85+言語)` でも認識できますが、参加者の言語が事前にわかっている場合は **`カスタム言語セット`** を選び、直下の **`⚙️ 変更`** から参加者の言語だけにチェックを入れる方が、似た発音の無関係な言語への誤判定が減り精度が向上します。

### 🎙️ 外部マイク選択・集音・VAD・区切り設定のコツ
- **外付け会議用スピーカーフォンやピンマイクを使うとき**:
  - `🎛️ 詳細・音響設定` ＞ **`マイク`** から使用するUSBマイク・ピンマイクを明示選択できます（一度録音を開始してマイク権限を許可すると正確なデバイス名が表示されます。万が一マイクを抜いても既定マイクへ自動フォールバックします）。
- **広い会議室・ヤード現場・騒がしい環境での設定**:
  - 離れた相手が小声の場合は `感度: 遠距離集音 (2.5x)` または `超遠距離 (3.5x)` と `VAD: 敏感` を組み合わせます。
  - 逆に工場・空調・屋外騒音が大きく `🎙️ 発話送信中` が消えない場合は、`VAD: 強め (騒音現場向け)` に切り替えると環境ノイズへの追従が速くなり、無音時のハルシネーションや通信量を抑えられます（感度ブーストを上げても Pre-Gain VAD 構造のためVAD閾値は狂いません）。
- **同時通訳スピード重視 vs 議事録の読みやすさ重視**:
  - 短いテンポの質疑応答で訳文を早く出したいときは `区切り: 標準・やや短め (2.2秒)`、プレゼンや長い説明を自然な日本語の段落でじっくり読みたいときは `区切り: 長文・文脈重視 (4秒)` または `超長文 (6秒)` が適しています。

### 🖥️ 画面表示・ショートカット・データ活用のコツ
- **プロジェクター投影・対面での画面共有・暗所作業**:
  - ヘッダ右上の **`🅰 標準 / 大 / 特大`** で対訳カードの文字を大きく表示でき、相手と一緒にタブレット画面を覗き込む対面通訳でも視認性が抜群です。薄暗い現場や長時間利用時は **`🌙`（ダークモード）** で目の負担とバッテリー消費を抑えられます。
- **マウスを使わない素早いキーボード操作**:
  - `Alt + R`（録音開始/停止）、`Alt + P`（一時停止/再開）、`Alt + Enter`（今すぐ翻訳）、`Alt + S`（サマリー出力）、`/`（タイムライン検索）を覚えておくと、メモを取りながらでも手を止めずに操作できます。
- **Excelでの課題管理表への転記**:
  - `📥 ファイル保存 ▾` ＞ **`📊 CSV (.csv)`** は UTF-8 BOM 付きで出力されるため、Windows / Mac の Excel でダブルクリックするだけで文字化けせずに開けます。
- **モバイル回線でのデータ通信量の目安**:
  - 音声ストリームは16kHzモノラルPCM単一送信＋VAD無音カットで最適化されており、連続発話時でも上り最大 **約 160 MB / 時間**、一般的な会議（発話率50%前後）では **約 70〜100 MB / 時間** 程度で安定稼働します。
