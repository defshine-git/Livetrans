# Gemini Live 日英・英日リアルタイム自動翻訳Webアプリ (v2.2.0)

Google Gemini Live API (`models/gemini-3.5-transcribe-live`) およびブラウザ標準音声認識（Web Speech API）に対応した、低遅延ストリーミング双方向音声翻訳・Googleドキュメント差分保存Webアプリケーションです。

---

## 新機能: QRコードによるPC設定のスマホ連携 (v2.2.0)

PCで設定した **Gemini APIキー**、**GAS Web App URL**、**GASシークレットトークン**、**翻訳設定** を、スマホのカメラでQRコードを読み取るだけで一発同期できる機能を追加しました。

### 使い方
1. **PC側の操作**:
   * 画面右上の「📱 スマホ連携」ボタンをクリックします。
   * スマホ連携用のQRコードが画面上に表示されます。
2. **スマホ側の操作**:
   * スマホの標準カメラアプリまたはQRコードリーダーで、PC画面のQRコードをスキャンして開きます。
   * ページが開くと同時にPC側の全設定がスマホの `localStorage` に自動インポートされ、「📱 PCからの設定をインポートしました！」と表示されます。
   * スマホの「翻訳を開始」をタップするだけで、キーの手動入力なしでそのまま翻訳を利用できます。

### 安全設計（セキュリティ仕様）
* 設定パラメータは URLのフラグメント（`#setup=...`）としてエンコードされます。
* URLフラグメントはブラウザ内部（クライアントサイド）でのみ処理され、GitHub Pagesや外部サーバーへのHTTPリクエストヘッダーに送信されることは一切ありません（サーバーアクセスログにAPIキーが残りません）。
* スマホ側で読み込み完了後、ブラウザのアドレスバーから自動的にフラグメントが消去（`history.replaceState`）され、画面上にも残りません。
* QRコード生成は外部API（3rd-party画像生成サーバー）に頼らず、同梱の `qrcode.js` によりブラウザローカル（Canvas）で完全オフライン描画されます。

## 構成ファイル一覧
* `index.html`: フロントエンドUI構造（スマホ連携ボタン、QRコードモーダル、診断コンソール完備）
* `style.css`: レスポンシブスタイルシート（QRコードモーダル、インプレース更新アニメーション対応）
* `app.js`: クライアント統合ロジック（差分同期、インプレースDOM、FIFOキュー、10分再接続、QR生成/インポート）
* `qrcode.js`: ブラウザ用スタンドアローンQRコード生成ライブラリ（完全クライアントサイド描画）
* `code.gs`: Google Apps Script バックエンド（差分追記、トークン認証、LanguageAppフォールバック翻訳）
* `README.md`: 本ドキュメント

## セットアップ手順

### 1. Google Apps Script (バックエンド) のデプロイ
1. [Google Drive](https://drive.google.com/) で「新規」>「その他」>「Google Apps Script」を開きます。
2. `code.gs` の内容をエディタに貼り付けて保存します。
3. （任意・推奨）画面左の「プロジェクトの設定」>「スクリプト プロパティ」で、プロパティ名 `SECRET_TOKEN`、値にお好きなパスコード（例: `MySecurePass2026`）を設定します。
4. 右上の「デプロイ」>「新しいデプロイ」をクリックし、「ウェブアプリ」を選択:
   - **次のユーザーとして実行**: 「自分」
   - **アクセスできるユーザー**: 「全員」
5. 「デプロイ」をクリックし、権限を承認後、発行された「ウェブアプリのURL」をコピーします。

### 2. GitHub Pages (フロントエンド) の公開
1. GitHub リポジトリを作成します。
2. `index.html`, `style.css`, `app.js`, `qrcode.js` をルートにコミット・プッシュします。
3. リポジトリの「Settings」>「Pages」で、Source を「Deploy from a branch (main / root)」に設定して保存します。
4. 発行された URL にブラウザ（Chrome または Edge 推奨）でアクセスします。

### 3. PCでの初期設定とスマホ連携
1. PCのブラウザで公開URLを開き、右上の「⚙️ 設定」で APIキー や GAS URL を登録して保存します。
2. 右上の「📱 スマホ連携」をクリックしてQRコードを表示します。
3. スマホのカメラでQRコードを読み取れば、スマホ側の設定が完了し、即座に通訳アプリとして利用可能になります。
