# Bilingual Transcriber - 現地監査音声認識・翻訳システム (v2.5.0)

Google Gemini Live API (`models/gemini-3.5-transcribe-live`) およびブラウザ標準音声認識（Web Speech API）に対応した、低遅延ストリーミング双方向音声翻訳・Googleドキュメント差分保存Webアプリケーションです。

---

## 主なUI・機能更新 (v2.5.0)
1. **2カラム対面監査グリッド表示（原文 / 訳文）**:
   - 発話カードを左右分割の2カラムグリッド形式に変更（左側: 原文、右側: 訳文）。
   - スマートフォン等の狭幅画面では自動的に1カラム縦並びに最適化されるレスポンシブデザイン。
2. **話者タグ切り替え機能（ローテーション）**:
   - 各カードの話者タグをクリックすることで、以下の役割をワンクリックで循環切り替え可能:
     - `Auditor (監査員)` (緑色バッジ)
     - `Yard Rep (ヤード担当者)` (黄色バッジ)
     - `Facility (施設側)`
     - `Other (その他)`
3. **インライン編集（✏️）機能**:
   - 各カードのアクションボタン「✏️」を押すことで、その場で原文・訳文をテキストエリアで直接修正・保存可能。
4. **カードごとの再翻訳（🔄）機能**:
   - 「🔄」ボタンを押すことで、修正後の原文を再度Gemini/GAS翻訳エンジンに投入して再翻訳を実行可能。
5. **議事録Markdown表形式コピー（📋 全履歴コピー）**:
   - 画面上部の「全履歴コピー」をクリックすると、以下のMarkdownテーブル形式でクリップボードにコピーされ、議事録やレポート作成に即座に活用可能:
     ```markdown
     # 現地監査 議事録 (HKC)

     | 時刻 | 話者 | 原文 | 訳文 |
     |---|---|---|---|
     | 14:20:05 | Auditor (監査員) | 本日の安全点検記録を確認させてください。 | Please let me check today's safety inspection records. |
     ```
6. **ライブ音声認識プレビュー表示**:
   - 青枠とリアルタイム音声メーターを備えた `live-card` バナーにより、発話中のリアルタイム認識テキストを強調表示。
7. **専門監査分野セレクト（HKC / EU-SRR / HSE / IHM / 全般）**:
   - 船舶リサイクル条約・環境安全管理の専門用語に対応したプロンプト連携。

8. **保存先Googleドライブフォルダの可変指定機能**:
   - 新規作成時、操作パネル上の「📁 保存先フォルダID/URL」入力欄から、任意のGoogleドライブフォルダIDまたは共有URLを直接指定可能。
   - 空欄の場合は既定のフォルダ（`15THrUI5WmO-aQIV7Nr5345jZEBOKDb8f`）に自動保存。
   - 「⚙️ 設定」モーダルからも既定のフォルダID/URLを恒久的に変更・保存可能。
   - 保存完了バナーから、作成されたドキュメントだけでなく「保存先フォルダ」へもワンクリックでアクセス可能。

9. **確定翻訳タイムラインの最新最上部（先頭追加）表示**:
   - 新しい発話が確定した際、タイムラインの最上部（先頭）に即座にカードが挿入され、過去の翻訳カードはスムーズに1段ずつ下方向へシフト。
   - 画面上部のリアルタイム認識プレビューから確定カードへの視線移動が最小化され、対面通訳・現場監査時の視認性が向上。

10. **動作最適化 & 遠距離集音・高感度化 (マイク感度コントロール)**:
   - **80Hz ハイパスフィルター**: 会議室の空調・換気扇の低周波ブーン音や机の振動ノイズをカットし、音声子音・母音の明瞭度を向上。
   - **プリアンプ・ゲインブースター (1.0x〜3.5x 可変)**: 遠くに座った人の小さな発話やささやき声を強力に増幅（デフォルト 2.5x 遠距離集音モード）。
   - **ダイナミクス・コンプレッサー**: 遠くの音をブーストしても、近くの人の大きな声で音割れ（クリッピング歪み）を起こさないよう、自動でピークを滑らかに圧縮制御。
   - **バッファプーリングによる超高速化**: 毎フレームの TypedArray アロケーションを排除し、長時間の連続対面監査でもガベージコレクションによるフレーム落ち（カクつき）を完全防止。
   - **過剰ノイズ抑制のバイパス**: ブラウザが遠くの微弱音声を雑音と誤認してミュートしてしまう問題を防止。
