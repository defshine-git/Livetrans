# Bilingual Transcriber - 現地監査音声認識・翻訳システム (v2.6.2)

Google Gemini Live API (`models/gemini-3.5-transcribe-live`) およびブラウザ標準音声認識（Web Speech API）に対応した、低遅延ストリーミング双方向音声翻訳・Googleドキュメント一元同期保存Webアプリケーションです。

---

## 🚀 主な新機能・アップデート (v2.6.x)

### 1. タブ・PC内部音声キャプチャ機能（イヤホン再生音の直接翻訳）
- **ワイヤレスイヤホンで聴いている音声を直接翻訳**:
  - 操作パネルの「音源:」から **「🖥️ タブ・PC音声」** を選択することで、YouTube、ウェビナー、オンライン会議（Teams/Zoom/Meet等）、英語動画などのPC再生音を直接デジタル信号としてキャプチャ可能。
  - 周囲の環境騒音が入らないため、マイク集音に比べて圧倒的に高い認識・翻訳精度を実現。
- **省電力・低負荷設計**:
  - `getDisplayMedia` で取得した映像トラックは即座に自動停止（`track.stop()`）し、音声トラックのみを16kHz Anti-Aliased PCMストリームへ変換して処理。
- **ブラウザ共有連動**:
  - ブラウザ上部の「共有を停止」ボタンに連動してアプリ側も自動で安全にセッション停止・保存処理を実行。

### 2. Googleドキュメント保存の安定化・一元同期（Single Document Sync）
- **同一ドキュメントへの完全同期**:
  - 従来の細切れな「差分追記方式」を廃止し、確定しているすべての発話・翻訳レコード（`finalizedRecords`）を**ひとつのGoogleドキュメントに集約・上書き同期**するアーキテクチャへ刷新。
  - セッション中に何度「Google ドキュメントに保存」を押しても、ドキュメントが毎回乱立せず、同一のドキュメントが常に最新状態で綺麗に更新。
- **編集・削除・再翻訳の完全反映**:
  - タイムライン上で発話をインライン修正（✏️）、再翻訳（🔄）、または不要発話を削除（🗑️）した場合でも、次回保存時にその変更がドキュメントへ100%忠実に反映。
- **堅牢な耐障害性と自動リカバリー**:
  - 翻訳未了やエラーが1件あっても確定済みレコードの保存が中断されない独立収集パイプライン。
  - 指定されたGoogleドキュメントIDが存在しない・削除されていた場合でも、自動的に新規ドキュメントを作成して確定翻訳を保護。
  - 通信タイムアウトを40秒に拡大し、大量発話時の保存中断を防止。

## 📋 全機能一覧

### 【対面通訳 & UI機能】
1. **2カラム対面監査グリッド表示（原文 / 訳文）**:
   - 発話カードを左右分割の2カラムグリッド形式で表示（左側: 原文、右側: 訳文）。
   - スマートフォン等の狭幅画面では自動的に1カラム縦並びに最適化されるレスポンシブデザイン。
2. **話者タグ切り替え機能（ワンクリックローテーション）**:
   - 各カードの話者タグをクリックすることで、以下の役割をワンクリックで循環切り替え可能:
     - `Auditor (監査員)` (緑色バッジ)
     - `Yard Rep (ヤード担当者)` (黄色バッジ)
     - `Facility (施設側)`
     - `Other (その他)`
3. **インライン編集（✏️）機能**:
   - 各カードの「✏️」ボタンから、その場で原文・訳文をテキストエリアで直接修正・保存可能。
4. **カードごとの再翻訳（🔄）機能**:
   - 「🔄」ボタンを押すことで、修正後の原文を再度Gemini/GAS翻訳エンジンに投入して再翻訳を実行可能。
5. **議事録Markdown表形式コピー（📋 全履歴コピー）**:
   - 画面上部の「全履歴コピー」をクリックすると、以下のMarkdownテーブル形式でクリップボードにコピー可能:
     ```markdown
     # 現地監査 議事録 (HKC)

     | 時刻 | 話者 | 原文 | 訳文 |
     |---|---|---|---|
     | 14:20:05 | Auditor (監査員) | 本日の安全点検記録を確認させてください。 | Please let me check today's safety inspection records. |
     ```
6. **リアルタイム音声認識プレビュー表示**:
   - 青枠とリアルタイム音声メーターを備えた `live-card` バナーにより、発話中のリアルタイム認識テキストを強調表示。
7. **確定翻訳タイムラインの最新最上部（先頭追加）表示**:
   - 新しい発話が確定した際、タイムラインの最上部に即座にカードが挿入され、過去のカードは下方向へシフト。

### 【音声・音響処理エンジン】
8. **マイク感度コントロール（遠距離集音ブースト）**:
   - **80Hz ハイパスフィルター**: 空調や机の振動ノイズをカットし、音声子音・母音の明瞭度を向上。
   - **プリアンプ・ゲインブースター (1.0x〜3.5x 可変)**: 遠席の小声やささやき声もクリアに増幅（デフォルト 2.5x 推奨）。
   - **ダイナミクス・コンプレッサー**: 遠くの音をブーストしても、近くの人の大声で音割れ（クリッピング歪み）を起こさないようピークを自動圧縮。
   - **バッファプーリング**: 毎フレームのメモリ確保を排除し、長時間の連続稼働でもフレーム落ちのない安定性を実現。
9. **デュアル音声認識エンジン & 自動フォールバック**:
   - 高度な多言語コードミキシングに対応した **Gemini Live API (`models/gemini-3.5-transcribe-live`)**。
   - WebSocket接続不可のネットワーク環境でもブラウザ組み込みの **Web Speech API** に自動フォールバックして稼働継続。

### 【Google Workspace / GAS連携】
10. **保存先Googleドライブフォルダの可変指定**:
    - 新規作成時、操作パネル上の「📁 保存先フォルダID/URL」から任意のGoogleドライブフォルダIDまたは共有URLを直接指定可能（空欄時は既定フォルダに自動格納）。
    - 「⚙️ 設定」モーダルからも既定フォルダID/URLを恒久的に変更可能。
11. **専門監査分野プロンプト連携**:
    - 香港条約（HKC）、EU-SRR、HSE、IHM、全般などの専門分野に応じた技術用語バイアスを翻訳プロンプトへ注入。

## 🛠️ ファイル構成

- `index.html`: Webアプリケーション本体画面（操作パネル、音源セレクト、ライブプレビュー、タイムライン、設定モーダル、QR連携モーダル）
- `app.js`: フロントエンド制御ロジック（マイク/PC音声キャプチャ、WebSocketクライアント、翻訳キュー、GAS通信、UI状態管理）
- `style.css`: レスポンシブ対応スタイルシート（2カラムグリッド、各話者バッジ、ステータス表示）
- `code.gs`: Google Apps Script バックエンド（Googleドキュメント一元同期保存、Driveフォルダ自動格納、LanguageAppフォールバック翻訳）
