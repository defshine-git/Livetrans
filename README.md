# Multilingual Transcriber - 多言語音声認識・翻訳システム (v3.2.0)

Google Gemini Live API (`models/gemini-3.5-transcribe-live`) およびブラウザ標準音声認識（Web Speech API）に対応した、国際会議・雑談・現地監査向けの多言語音声認識・コードスイッチング（混在発話）対応・長文文脈翻訳・任意範囲サマリー・Googleドキュメント一元同期Webアプリケーションです。

---

## 🚀 主な機能・特徴 (v3.2.0 完全多言語対応リリース)

### 1. v3.2.0 完全多言語化 ＆ 英語・日本語最優先＋ヒンディー語/ウルドゥー語混在対応
- **4段階の認識プロファイル (`#select-recognition-profile`)**:
  - **🎯 英語・日本語 最優先 ＋ ヒンディー/ウルドゥー混在対応 (`ja-en-hi-ur`・既定)**: `['ja-JP', 'en-US', 'en-IN', 'hi-IN', 'ur-PK']` の音響バイアスとインド英語アンカー (`en-IN`) により、英語・日本語の認識精度を最優先で維持しつつ、英語の雑談に混じるヒンディー語・ウルドゥー語（デーヴァナーガリー文字・ナスタアリーク体ウルドゥー文字・ローマ字 Hinglish / Roman Urdu）を自然に拾い上げます。
  - **🌐 フル多言語自動判別 (`multilingual-auto`・85+言語)**: Gemini 3.5 Live のネイティブ自動言語識別 (`languageCodes: []`) を開放し、85以上の言語および自由なコードスイッチングを自動認識（未登録言語も `Intl.DisplayNames` で日本語言語名を動的解決）。
  - **🧩 カスタム多言語セット (`multilingual-custom`)**: 設定モーダルから最大20言語（南アジア重視・アジア製造/海事・欧米グローバルの一括プリセット付）を任意選択し、対象言語群へ認識精度を集中。
  - **🔒 英語・日本語のみ厳密ロック (`strict-ja-en`)**: `['ja-JP', 'en-US', 'en-IN']` のみに厳密固定し、アクセントのある英語も英語として認識しつつ他言語文字の混入を完全抑止。
- **混在発話（コードスイッチング）を分断しない長文バッファリング＆文脈翻訳**:
  - 英語発話の途中にヒンディー語・ウルドゥー語の相槌やフレーズ（`acha`, `theek hai`, `yaar`, `انشاءاللہ`, `सब ठीक है` 等）が混じってもカードを細切れに分割せず1つの段落として結合し、英語＋ヒンディー語/ウルドゥー語双方のニュアンスを汲み取って自然な日本語（または指定言語）へ一括翻訳。
  - 混在発話カードには `🇺🇸·🇮🇳` (`EN+HI`) や `🇺🇸·🇵🇰` (`EN+UR`) の複合言語バッジを自動付与。
- **多言語翻訳ルーティング＆相手言語セレクタ（20言語）**:
  - `自動双方向 (日本語 ⇄ 相手言語)` / `全言語 ➔ 日本語に集約` / `全言語 ➔ 相手言語に集約` / `固定: 日本語 ➔ 相手言語` / `固定: 英語 ➔ 日本語 (英語ロック)` に対応。同一言語のみの発話はAPI呼び出しを自動スキップして高速パススルー表示。
- **RTL（右横書き）混在レンダリング＆多言語フォント最適化**:
  - ウルドゥー語・アラビア語・ペルシア語等の RTL 文字と英語（LTR）が1文中に混在しても文字順序が崩れない双方向レンダリング（`dir="auto"`, `<bdi>`, `unicode-bidi: plaintext`）と、ウルドゥー語句読点（`۔`, `؟`, `،`）での自然な長文分割に対応。
- **会議カテゴリ拡張（既定: `全般 (Common)`）＆ HInglish プリセット追加**:
  - 既定カテゴリを汎用的な `全般 (Common)` に変更し、`雑談・一般会議 (Casual)` および従来の専門監査カテゴリ（`HKC`, `EU-SRR`, `HSE`, `IHM`）を選択可能。ワンクリックの `💬 英雑談＋ヒンディー/ウルドゥー` プロンプトプリセットも搭載。

### 2. v3.1.1 基盤最適化・スマホUI・QR連携機能
- **共通テキストAPIクライアント統合 (`GeminiTextClient`)**: 翻訳とサマリーで Gemini REST API カスケードフォールバック・最適モデルキャッシュを共有。
- **スマホ向けカードヘッダの1行スリム化＆操作プルダウン化**: コピー・修正・再翻訳・削除を `⋯ ▾` メニューへ集約し、スマホ画面でも1行表示を維持。
- **スマホ連携QRコードの超軽量化・鮮明描画化**: 既定値省略（v3.2.0の新規項目も既定値時は0バイト追加）・GASデプロイID圧縮・プリセットID化・Base64URL化により高密度化を防ぎ、カメラ読み取り性を確保。
- **排他制御＆ロケール互換フェイルセーフ**: 録音二重起動ロック、Googleドキュメント多重保存ロックに加え、万一API側で未対応ロケールエラー (`1007`) が返った場合は自動的に `languageCodes: []`（全言語自動判別）へフォールバック再接続。

### 3. 高精度VAD（音声区間検出）＋ モバイル・Wi-Fi安定化
- **Pre-Gain VAD＋Minimum Statistics 適応ノイズ追跡 (`VoiceActivityDetector`)**:
  - マイク感度変更（1.0x〜3.5x）の影響を受けない Pre-Gain 分岐解析と直近 2.8 秒の最小 RMS 追跡により、騒音下での送信張り付きを防止。
  - **プリロール（400〜550ms）**・**ハングオーバー（1.4〜2.2秒）**・**200〜3,600Hz 音声帯域比解析**により、語頭欠けを防ぎつつ無音時の通信量・API課金・ハルシネーションを大幅削減。
- **省帯域 `audio` 単一送信＆瞬断時自動リトライ**: 必要上り帯域を約 0.4 Mbps（約 160 MB / 時間）に抑え、回線瞬断時は最大5回自動再接続。

### 4. 任意タイミング・可変さかのぼり範囲の日本語サマリー出力 (`SummaryService`)
- 録音・翻訳を止めずに **「✨ サマリー出力」** から `直近 3/5/10/15/30/60分 / セッション全体 / カスタム分数指定` の多言語・混在会話を構造化**日本語サマリー**（要点・主なトピック・確認事項/課題）として出力・履歴切替・Markdownコピー可能。

### 5. Googleドキュメント一元同期 (`code.gs` v3.2.0)
- 多言語・混在言語ラベル（`EN+HI`, `EN+UR` 等）や `Common` / `Casual` カテゴリを含む議事録を単一Googleドキュメントへ完全上書き同期保存（既存の v2.9.0 / v3.1.1 デプロイ済み GAS Web App とも完全後方互換でそのまま動作します）。
