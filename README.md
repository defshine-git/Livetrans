# Bilingual Transcriber - 現地監査音声認識・翻訳システム (v2.5.0)

Google Gemini Live API (`models/gemini-3.5-transcribe-live`) およびブラウザ標準音声認識（Web Speech API）に対応した、低遅延ストリーミング双方向音声翻訳・Googleドキュメント差分保存Webアプリケーションです。

---

## 主なUI・機能更新 (v2.5.0)
1. **2カラム対面監査グリッド表示（原文 / 訳文）**:
   - 発話カードを左右分割の2カラムグリッド形式に変更（左側: 原文、右側: 訳文）。
   - スマートフォン等の狭幅画面では自動的に1カラム縦並びに最適化されるレスポンシブデザイン。
2. **話者タグ切り替え機能（ローテーション）**:
   - 各カードの話者タグをクリックすることで、以下の役割をワンクリックで循環切り替え可能:
     - `Auditor (監査員)` (緑色バッジ)
     - `Yard Rep (ヤード担当者)` (黄色バッジ)
     - `Facility (施設側)`
     - `Other (その他)`
3. **インライン編集（✏️）機能**:
   - 各カードのアクションボタン「✏️」を押すことで、その場で原文・訳文をテキストエリアで直接修正・保存可能。
4. **カードごとの再翻訳（🔄）機能**:
   - 「🔄」ボタンを押すことで、修正後の原文を再度Gemini/GAS翻訳エンジンに投入して再翻訳を実行可能。
5. **議事録Markdown表形式コピー（📋 全履歴コピー）**:
   - 画面上部の「全履歴コピー」をクリックすると、以下のMarkdownテーブル形式でクリップボードにコピーされ、議事録やレポート作成に即座に活用可能:
     ```markdown
     # 現地監査 議事録 (HKC)

     | 時刻 | 話者 | 原文 | 訳文 |
     |---|---|---|---|
     | 14:20:05 | Auditor (監査員) | 本日の安全点検記録を確認させてください。 | Please let me check today's safety inspection records. |
     ```
6. **ライブ音声認識プレビュー表示**:
   - 青枠とリアルタイム音声メーターを備えた `live-card` バナーにより、発話中のリアルタイム認識テキストを強調表示。
7. **専門監査分野セレクト（HKC / EU-SRR / HSE / IHM / 全般）**:
   - 船舶リサイクル条約・環境安全管理の専門用語に対応したプロンプト連携。
