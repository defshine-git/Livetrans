# Bilingual Transcriber - 現地監査音声認識・翻訳システム (v2.8.0)

Google Gemini Live API (`models/gemini-3.5-transcribe-live`) およびブラウザ標準音声認識（Web Speech API）に対応した、低遅延ストリーミング双方向音声翻訳・Googleドキュメント一元同期保存Webアプリケーションです。

造船所・船舶解体ヤード（インド・アラン、バングラデシュ・チッタゴン等）や海外現地工場での監査実務を想定し、**日本語・英語・ベンガル語・ヒンディー語** の4言語自動認識、iPad/スマートフォン対応、およびシステムプロンプトの任意調整機能を備えています。

---

## 🚀 主な機能・特徴 (v2.8.0)

### 1. 4言語（日・英・ベンガル・ヒンディー）同時自動認識・翻訳
- **韓国語・スワヒリ語等の誤認識・ハルシネーション防止**:
  - Gemini Live の WebSocket Setup 時に `inputAudioTranscription.languageCodes` として `['ja-JP', 'en-US', 'bn-BD', 'bn-IN', 'hi-IN']` を指定。
  - 音響モデルの探索範囲を厳密に制限することで、騒音環境で日本語が韓国語やスワヒリ語等に誤判定される現象を完全に防止。
- **バングラデシュ現地実務に即した翻訳ルーティング**:
  - バングラデシュ人ヤード関係者が英語を話す中に混ざるベンガル語やヒンディー語（Benglish / コードミキシング）を文脈全体から自然な**日本語**へ一方向翻訳。
  - 日本語からの逆翻訳は国際共通語である**英語**へ翻訳（不要な日本語➔ベンガル/ヒンディー逆翻訳を排除）。
- **リアルタイム文分割 (StreamSentenceSplitter) の多言語対応**:
  - ベンガル語・ヒンディー語の文末記号である **ダンダ（`।`）** および **ダブルダンダ（`॥`）** を文末判定パターンに組み込み、文単位での即時確定翻訳を実現。
- **言語バッジ表示と Markdown 議事録出力**:
  - 原文カードに `🇯🇵 日本語`、`🇺🇸 英語`、`🇧🇩 ベンガル語`、`🇮🇳 ヒンディー語` のバッジを自動表示。
  - クリップボードコピー時にも「言語」列を含めた5カラムの Markdown 表形式で出力可能。

### 2. Gemini Live `systemInstruction`（プロンプト指示文）の任意調整
- **設定画面からの直接編集**:
  - 「⚙️ 設定」画面から、Gemini Live の音声認識エンジンへ渡すシステムプロンプト（`systemInstruction`）を自由に編集・保存可能。
  - 認識言語の優先度、専門用語の表記ルール、除外したい語句などを現場に合わせて任意にチューニング可能。
- **初期値リセットボタン**:
  - 「初期値に戻す」ボタンにより、推奨の初期指示文（4言語制約・コードミキシング対応）へいつでもワンタップで復元。
- **QRコード経由での端末間同期**:
  - PCでカスタマイズした指示文は、スマホ連携QRコードを通じて iPad やスマートフォンへも自動同期。

### 3. iPad / iPadOS / iOS 完全対応
- **Web Audio API の即時アンロック**:
  - 「録音開始」タップ時の同一コールスタック内で `AudioContext` を初期化・再開し、無音バッファを再生して iOS WebKit の `suspended` 停止問題を完全解消。
- **マイク取得（getUserMedia）の標準化と段階的フォールバック**:
  - 非標準の `goog*` 制約を排除し、標準制約 ➔ 最小制約 ➔ `{ audio: true }` へ自動フォールバック。
- **WebKit ガベージコレクション対策**:
  - アクティブなオーディオノード一式をグローバル参照（`window._activeAudioSession`）として安全に保持し、録音セッション中の音声途切れを防止。
- **Web Speech API 継続認識のリカバリー**:
  - iOS Safari で 1文ごとに `onend` が発火する仕様に対し、200ms 遅延での再起動およびインスタンス自動再生成ロジックを搭載。

### 4. スマートフォン操作性の最適化
- **仮想キーボード対応モーダルスクロール**:
  - 設定モーダルを独立スクロール化（`overflow-y: auto; max-height: calc(100dvh - 20px)`）し、ソフトウェアキーボード表示時でも「設定を保存」ボタンが画面外に押し出されず確実に操作可能。
- **背景スクロール連動の抑止**:
  - モーダル表示中は背面のメイン画面スクロールを自動ロック（`modal-open`）。
- **タッチ操作遅延解消**:
  - `touch-action: manipulation` により、モバイル特有のダブルタップズーム判定（300ms 遅延）を解消し軽快なレスポンスを実現。
- **クリップボードコピーのフォールバック**:
  - `navigator.clipboard` が制限された環境でも `document.execCommand('copy')` で確実にコピー可能。

### 5. Google ドキュメント一元同期保存（Single Document Sync）
- **同一ドキュメントへの完全同期**:
  - 確定した全発話・翻訳レコードを**ひとつの Google ドキュメントに集約・上書き同期**。
  - セッション中に何度保存を押してもドキュメントが乱立せず、常に最新状態で更新。
- **インライン修正・削除・再翻訳の忠実な反映**:
  - タイムライン上で発話をインライン修正（✏️）、再翻訳（🔄）、または不要発話を削除（🗑️）した場合でも、次回保存時にその変更がドキュメントへ100%反映。
- **可変フォルダ指定**:
  - 操作パネルおよび設定画面から任意の Google ドライブ保存先フォルダ ID / URL を直接指定可能。

### 6. タブ・PC内部音声キャプチャ（PCのみ）
- **イヤホン再生音の直接翻訳**:
  - 「音源:」から **「🖥️ タブ・PC音声」** を選択することで、オンライン会議（Teams/Zoom/Meet等）や英語動画などのPC再生音を直接デジタルキャプチャ。
  - 周囲の環境騒音が入らないため、高精度な認識・翻訳が可能（※iPad/iOS環境では非対応のため自動でマイクに切り替わります）。

### 7. 音声・音響処理エンジン（遠距離集音ブースト）
- **80Hz ハイパスフィルター**: 空調や机の振動ノイズをカットし、音声の明瞭度を向上。
- **プリアンプ・ゲインブースター (1.0x〜3.5x)**: 遠席の小声やささやき声もクリアに増幅（推奨 2.5x）。
- **ダイナミクス・コンプレッサー**: 近くの人の大声で音割れ（クリッピング歪み）を起こさないようピークを自動圧縮。
- **バッファプーリング**: 毎フレームのメモリ確保を排除し、長時間の連続稼働でもフレーム落ちのない安定性を実現。

## 📖 使い方

### 1. 初期設定
1. ブラウザで `index.html` を開きます。
2. 画面右上の **「⚙️ 設定」** を開きます。
3. **Gemini API キー** を入力します（Google AI Studio で取得したもの）。
4. （任意）Google ドキュメント保存を利用する場合は **GAS Web App URL** を入力し、「GAS接続テスト」をクリックして疎通を確認します。
5. （任意）認識させたい言語の優先順位や専門用語のルールを調整したい場合は、**Gemini Live systemInstruction** を編集します。
6. **「設定を保存」** をクリックします。

### 2. スマホ・iPad 連携（QRコード）
1. PC で設定を完了後、画面右上の **「📱 スマホ連携」** をクリックします。
2. 表示された QR コードを iPad やスマートフォンのカメラでスキャンします。
3. API キー、GAS 設定、翻訳設定がスマホ側へ自動同期されます。

### 3. 録音・リアルタイム翻訳の開始
1. 操作パネルの **「録音開始」** ボタンをクリック／タップします（初回はマイクアクセスを許可してください）。
2. 話しかけると、上部の `livePreview` にリアルタイムで認識テキストが表示されます。
3. 文の区切りで自動確定し、下のタイムラインに左右2カラム（左: 原文、右: 訳文）で追加されます。
4. 各カードの話者タグ（Auditor / Yard Rep 等）をクリックすると、話者役割を切り替えられます。
5. 原文・訳文の修正（✏️）、再翻訳（🔄）、コピー（📋）、削除（🗑️）が可能です。

### 4. Google ドキュメントへの保存
1. 画面右上の **「💾 Google ドキュメントに保存」** をクリックします。
2. 確定している全レコードがひとつの Google ドキュメントへ綺麗に同期保存されます。
3. 保存完了後、画面上にドキュメントへの直リンクバナーが表示されます。
